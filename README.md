# COUNTRIX-Real-Time-Object-Classification-Counting-System
Countrix is an object classification system that uses an ESP32-CAM, Arduino UNO, and YOLOv8n to detect, classify and count different classes of objects such as coins, screws, bolts, and nuts. The ESP32 provides live feedback to the custom-trained YOLOv8n object detection model to identify objects and locate them using bounding boxes.
